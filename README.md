# House Price Prediction Using Machine Learning

## Objective
Predict house values using numerical housing features and a Linear Regression model.

## Dataset
California Housing dataset from Scikit-learn.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Median income
- House age
- Average rooms
- Average bedrooms
- Population
- Average occupancy
- Latitude
- Longitude

## Methodology
1. Load and explore the dataset.
2. Visualize house value distribution.
3. Handle missing values using median imputation.
4. Normalize features using StandardScaler.
5. Split data into training and testing sets.
6. Train a Linear Regression model.
7. Evaluate predictions using MSE, RMSE, MAE, and R2 score.
8. Compare actual and predicted house values.
